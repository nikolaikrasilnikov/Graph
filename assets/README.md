# Agent identity

`openai.svg` is the unmodified white monoblossom from OpenAI's official asset pack, downloaded 2026-09-19: https://cdn.openai.com/brand/OpenAI-Logos-2025.zip . It identifies the OpenAI provider for Codex, not the Graph product. Guidelines: https://openai.com/brand/ . OpenAI owns its marks.

`claude.svg` is a small pixel rendition of the Claude Code mascot, based on the user's supplied terminal reference. It identifies Claude; no invented mascot is used for other providers. Unknown providers fall back to their name.
