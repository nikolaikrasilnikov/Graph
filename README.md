# Graph Studio

Локальный граф задач для Codex CLI и Claude Code. Graph планирует этапы, запускает их через Herdr, передаёт результаты зависимостей и показывает итог, включая блокировки и частично выполненную работу.

## Установка на Windows x64

1. Скачайте Graph-v0.3.0-windows-x64.zip из [Releases](https://github.com/nikolaikrasilnikov/Graph/releases/latest), распакуйте в постоянную папку с правом записи.
2. Запустите **Setup.cmd**. Нужны интернет, Windows 10/11 x64, PowerShell 5.1+ и tar.exe. Права администратора не требуются.
3. Запустите **Login-Codex.cmd** и войдите в свой аккаунт. Авторизация автора не переносится. Используется модель по умолчанию вашего Codex; доступность и оплата зависят от вашего аккаунта.
4. Откройте ярлык **Graph** на рабочем столе. Он запускает отдельную сессию Herdr и локальный сервер, затем браузер. Альтернатива — Start-Graph.cmd.
5. Заполните library/projects/example/BRIEF.md и укажите рабочую папку исходников в проекте Graph. Подключите нужные материалы из library.

Для агента, который устанавливает и настраивает систему: **[INSTALL-FOR-AGENT.md](INSTALL-FOR-AGENT.md)**. О передаче контекста: **[GRAPH-AGENT-DATA-HANDOFF.md](GRAPH-AGENT-DATA-HANDOFF.md)**.

Установщик проверяет хеши загрузок из [dependencies.lock.json](scripts/dependencies.lock.json). Node.js, Git и gh могут использоваться из PATH; Herdr и Codex загружаются в .runtime. Для всех закреплённых версий используйте powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1 -UseBundledTools. В .runtime сохраняется весь пакет Herdr с ConPTY и весь пакет Codex с его вспомогательными программами.

Повторный Setup сохраняет существующий config.json и содержимое библиотеки. Для перенастройки предусмотрен -Reconfigure; он сохраняет резервную копию конфигурации, но параметры следует передать заново. При переносе папки на другой компьютер запустите установку заново: абсолютные пути создаются локально.

## GitHub

Login-GitHub.cmd выполняет gh auth login и настройку Git для HTTPS. В проекте задайте рабочую папку Git и owner/repository. Проверьте готовность GitHub в интерфейсе. Передача токена исполнителям отключена по умолчанию: включайте githubAgentAuth в локальном config.json только с разрешения владельца аккаунта. При включении агент получает токен в окружении процесса и может его прочитать; токен не вставляется в задания Graph. Авторизация не обходит права репозитория и правила веток.

Задача публикации должна явно поручать push/релиз. Успешное завершение CLI само по себе не считается доказательством публикации: агент должен вернуть ссылку и результат проверки. Если он сообщает partial/blocked по протоколу Graph, причина отображается в итоговом результате и зависимые этапы не запускаются.

## Данные и ограничения

- config.json: локальные пути и настройки, не входит в Git.
- library/: ваша библиотека; library-template/: нейтральные исходные шаблоны.
- .graph-data/: проекты, графы, снимки контекста, результаты и журналы запусков.
- .runtime/ и .downloads/: инструменты и проверяемые загрузки.
- Сервер слушает только loopback. Это локальный инструмент для одного доверенного пользователя; не открывайте порт в интернет.
- Подключённый skill не устанавливает MCP или инструменты. CLI использует собственную конфигурацию и доступные ему возможности.
- Claude Code необязателен: установите и авторизуйте его отдельно, передайте setup.ps1 -ClaudePath с путём к исполняемому файлу. Базовая установка использует Codex.

## Проверки и диагностика

Node.js 22+: node --test tests/*.test.mjs. Никакие модельные вызовы не нужны для модульных тестов.

Если ярлык не запускается, проверьте startup-error.log, server-error.log и herdr-error.log. При занятом порте выберите другой port и соответствующий herdrSession в config.json. Не закрывайте чужую сессию Herdr. Закрытие вкладки браузера не останавливает сервер.

Исходные документы сторонних инструментов: [Herdr Windows](https://herdr.dev/docs/windows-beta/), [Herdr install](https://herdr.dev/docs/install/), [Codex CLI](https://learn.chatgpt.com/docs/codex/cli), [Node.js](https://nodejs.org/), [Git for Windows](https://gitforwindows.org/), [GitHub CLI](https://cli.github.com/). Эти инструменты загружаются из официальных источников и распространяются на собственных условиях; Graph ZIP не содержит их бинарников.
