# v0.3.0

- Установка на Windows x64: проверяемые загрузки Node.js, Herdr с ConPTY, Codex с вспомогательными программами, Git и GitHub CLI.
- Стартовая библиотека, инструкция для устанавливающего агента и ярлык рабочего стола.
- Отдельная сессия Herdr, обнаружение конфликта порта, модель Codex из настроек владельца.
- Продолжение мастер-плана из сохранённого результата без повторного запуска завершённых предков.
- Диагностика CLI в терминале и явный итог при блокировке или неудачной публикации.
- Опциональная передача GitHub-авторизации исполнителям с разрешения владельца.

Личные настройки, библиотека, журналы и бинарные зависимости не включаются в исходники и ZIP. Подробности установки и её ограничений: INSTALL-FOR-AGENT.md.
