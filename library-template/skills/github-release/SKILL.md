---
name: github-release
description: Публикация явно порученного релиза после проверки репозитория, авторизации, тестов и состава архива.
---

Проверь рабочую папку, owner/repository, git status, gh auth status и права целевого репозитория. Авторизация CLI не означает разрешение публиковать любой проект: следуй поручению пользователя.

Не включай config.json, секреты, рабочую библиотеку, журналы или личные абсолютные пути в коммит и архив. Выполни проверки, подготовь описание и контрольные суммы. После публикации проверь тег, URL релиза и наличие файлов.

Если публикация не состоялась, сообщи причину и уже подготовленные артефакты. Заверши ответ маркером graph-outcome со status blocked или partial по протоколу Graph; не выдавай локальный архив за опубликованный релиз.
