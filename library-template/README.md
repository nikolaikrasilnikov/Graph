# Стартовая библиотека Graph

Это нейтральные шаблоны, а не копия библиотеки автора. Установщик копирует только отсутствующие файлы в libraryRoot.

До первого запуска задачи заполните projects/example/BRIEF.md: цель, рабочий репозиторий, ограничения, критерии приёмки. Затем подключите конкретный проект и нужные skills к планировщику Graph. Не прикладывайте всю библиотеку каждому этапу.

skills — короткие инструкции по видам работы; projects — знания конкретного проекта; memory — проверенные долговременные выводы; recipes — необязательные примеры последовательностей. Секреты, журналы CLI, node_modules и результаты запусков здесь не хранить.
